Code signing

Code signing policy

How Hopp's installer is built and signed, and who decides what gets signed.

Free code signing provided by SignPath.io, certificate by SignPath Foundation. Hopp has applied; until the application is approved, the installer isn't signed yet and Windows may warn about an unknown publisher.

What is signed

The Hopp installer for Windows. It is built automatically by GitHub Actions from the source code in github.com/chillscapee-netizen/Hopp, and only that build is sent for signing. Nothing built on someone's own computer is signed.

Who does what

Committers and reviewers: Marcus. Changes from anyone else are reviewed before they're taken in.

Approvers: Marcus. Every release is approved by hand before it's signed.

Privacy

Hopp talks to the internet only for what you use it for:

  • Hopp Cloud: your account, your servers and messages, and whether a new version of Hopp is out.
  • Servers you join, and your friends' computers while you're in a call or voice channel with them.
  • For calls to find a way between computers: Google's and Cloudflare's connection helpers (STUN), and Cloudflare's relay when a direct way doesn't work.
  • When a link is shared in a chat: that web page, to show a preview of it (turn previews off in Settings → Privacy & safety). YouTube, when a YouTube link is shown.
  • KLIPY, when you search for GIFs and when GIFs are shown.

Nothing is sent anywhere else, and Hopp has no ads or tracking. What Hopp keeps, and what's encrypted.
