      Run your own server

      Hopp has no central server that someone has to pay for. Each community is run by someone in it.

      1. Start the server On a computer that's on when you hang out, or on a free cloud server if it should be up around the clock. strom-server --name "My server"
      2. Connect and become the owner The first person to connect from the same computer becomes the owner. Nobody else can get in without an invite.
      3. Invite people Open the server menu and choose Invite people. You decide how long each link works and how many can use it.
      People who join can only chat and talk. They can't reach your files. They will see your IP address, though, so if you're inviting strangers, run the server on a cloud server instead of your home computer.
